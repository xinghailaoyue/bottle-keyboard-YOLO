# 模型版本说明

三个正式版本使用相同的类别编号：`0=bottle`，`1=keyboard`，输入尺寸均为 640×640。

| 版本 | 起始权重 | 训练图片 | 主要目的 | 权重文件 |
|---|---|---:|---|---|
| V1 baseline | COCO 预训练 YOLO11n | 360 | 建立瓶子/键盘基线 | `bottle_keyboard_yolo11n_best.pt` |
| V2 expanded | V1 best | 599 | 增加样本与人物困难负样本，减少误报 | `bottle_keyboard_yolo11n_expanded_best.pt` |
| V3 horizontal | V2 best | 1000 | 强化横放瓶子，同时保留键盘与负样本能力 | `bottle_keyboard_yolo11n_horizontal_v3_best.pt` |

## V1

- Open Images：288 张训练图、72 张验证图。
- 最佳整体 mAP50：0.775；mAP50-95：0.596。
- 瓶子召回率低于键盘，容易漏检。

## V2

- Open Images：479 张训练图、120 张验证图。
- 总计 599 张，其中含 60 张人物困难负样本。
- 相同 V2 验证集上整体 mAP50 为 0.7751、mAP50-95 为 0.6393。
- 人物负样本上的 bottle 误报框从 V1 的 16 个下降为 3 个。

## V3

- 800 张训练图、200 张验证图，总计 1000 张。
- 保留 V2 的 599 张 Open Images 图片。
- 新增 401 张 COCO 2017 train 图片：280 张横放瓶子、80 张键盘、41 张人物困难负样本。
- 横放瓶子筛选条件：瓶子框宽高比≥1.5、宽≥40px、高≥15px、框面积占整图≥0.5%。
- 从280张横放瓶子中分层留出56张用于验证；它们不会参与训练。
- V3 完成全部60轮训练；混合验证集最佳 mAP50 为0.6156，最佳 mAP50-95为0.3934。
- 在56张横放瓶子留出图上，检出率由 V2 的21.4%提高到 V3 的67.9%。
- 完整结果与旧验证集上的性能取舍见 `docs/V3_TRAINING_REPORT.md`。

## 为什么 V3 从 V2 微调

V2 已经具有稳定键盘识别和较低人物误报。V3 使用较低学习率从 V2 继续训练，而不是从零开始，
目的是学习横放瓶子的形状与上下文，同时尽量降低对原有能力的破坏。训练设置了 `patience=20`
早停，并使用较温和的 mosaic、旋转、缩放和翻转增强。
